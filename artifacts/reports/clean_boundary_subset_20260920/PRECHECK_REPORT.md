# Strict-subset precheck

Passed input hashes, 100-label contract, real raw-core normalization and MPS model outputs. A full curation dry run retained 8,367 complete/non-overlapping cores from 11,936 annotated events: 1,536 known and 6,831 unknown, plus 42,111 boundary windows from complete ASLLRP crops. Every retained core has at least four raw target observations covering both annotated edges. The run is evaluation-only and cannot access Citizen test.
